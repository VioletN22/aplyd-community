Frontend Engineer

Sydney · Full-time · Hybrid

We are looking for a Frontend Engineer to join the editor team. You will build the experiences that tens of millions of people use to design every day, working in TypeScript and React across a large, well-tested codebase.

What you'll do: own features end to end, from the first sketch with design to measuring impact after launch. Improve performance of the editor on low-end devices. Mentor interns and contribute to our component library.

About you: 2+ years of experience building web applications. Strong skills in JavaScript, CSS and accessibility. Experience with state management and testing. Bonus if you have worked on graphics or canvas-heavy apps.

Benefits include equity, flexible working, and a learning budget. Apply with your resume and a short note.
